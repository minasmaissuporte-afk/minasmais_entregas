---
name: Fidelidade visual do PWA do motoboy
description: Orientação do usuário para mudanças visuais no PWA de entregas.
---

Para mudanças visuais no PWA do motoboy, use o design oficial do Figma como referência principal e compare os estados solicitados no viewport de 390×844. Quando o Figma não estiver acessível, use os PNGs fornecidos pelo usuário e diga explicitamente que essa foi a referência. Não afirme correspondência visual autenticada se a captura do Preview não conseguir abrir a área autenticada.

**Why:** O usuário apontou que uma implementação anterior ficou muito diferente do Figma e pediu validação visual honesta antes de concluir.

**How to apply:** Consulte o arquivo oficial no Figma antes de futuras mudanças de UI do motoboy; valide a tela autenticada no Preview quando possível e registre qualquer limitação de captura.
